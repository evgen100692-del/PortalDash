# PortalDash — Дашборд по химии

Интерактивный дашборд для учёта закупок, расхода и остатков автохимии по объектам сети.

## Стек

- **Backend:** Node.js + Express + better-sqlite3
- **Frontend:** HTML/CSS/JS (Vanilla) + Chart.js
- **PDF-экспорт:** PDFKit
- **Excel импорт/экспорт:** ExcelJS + xlsx

## Оформление

Чёрно-рыже-белая палитра: тёмный фон, белый текст, оранжевые акценты (см. `public/css/theme.css`).

## Быстрый старт

```bash
npm install
npm run import   # разово: парсит Excel из data/ и заполняет SQLite
npm start        # запускает сервер на http://localhost:3000
```

## Модули дашборда

1. **Карточка объекта** — адрес, ТУ-ответственный, телефон, остатки по всем видам химии, история поставок/списаний за период.
2. **Сводная аналитика** — графики "закуплено vs списано vs остаток" по неделям/месяцам с фильтрами (объект, вид химии, ТУ, город).
3. **Тепловая карта расхода** — рейтинг объектов по перерасходу химии.
4. **Реестр поставщиков** — статус (используется/тест/отказ), причины отказа, цена закупки vs франчайзи.
5. **Уведомления по остаткам** — пороги минимального остатка, автоматическая пометка "требует заказа".
6. **Финансовый блок** — динамика стоимости закупок по неделям/поставщикам.
7. **Экспорт отчётов** — PDF/Excel по объекту или периоду.

## Импорт данных

Скрипт `server/etl/importExcel.js` разбирает исходные файлы вида «заказ автохимия 20XX.xlsx» (широкие таблицы с недельными срезами: Списание/Остаток/Доставка/Стоимость на каждую неделю по каждому объекту) и «Khimiia-Portal.xlsx» (справочник номенклатуры и поставщиков), нормализуя их в реляционную схему SQLite (см. `server/schema.sql`).

Перед первым запуском положите файлы закупок в `data/` и при необходимости скорректируйте маппинг листов/колонок в `importExcel.js` — под точный набор листов текущего года (структура листов может расширяться: Аминат, Реагент, Оч. Дисков, HydroBlock и т.д.).
