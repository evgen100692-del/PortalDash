# PortalDash

## Запуск на Node.js 24

Требуется Node.js 24.15.0 или новее.

```powershell
cd D:\Projects\PortalDash
npm ci
npm start
```

Откройте http://localhost:3000.

## Доступ из локальной сети

По умолчанию сервер слушает на всех интерфейсах (`0.0.0.0`), поэтому к нему можно
подключаться с других устройств в той же сети.

1. Запустите `npm start`. В консоли появятся строки вида:

   ```
     локально:      http://localhost:3000
     в этой сети:   http://192.168.1.42:3000
   ```

2. Один раз разрешите порт во входящих правилах брандмауэра Windows
   (PowerShell **от имени администратора**):

   ```powershell
   New-NetFirewallRule -DisplayName "PortalDash 3000" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 3000
   ```

   Удалить правило позже: `Remove-NetFirewallRule -DisplayName "PortalDash 3000"`.

3. На другом устройстве (в той же сети/Wi-Fi) откройте адрес из строки
   «в этой сети», например `http://192.168.1.42:3000`.

Примечания:

- Другой порт: `$env:PORT = "8080"; npm start` (правило брандмауэра — на тот же порт).
- Только локальный доступ: `$env:HOST = "127.0.0.1"; npm start`.
- Если сеть отмечена как «Общедоступная», Windows жёстче режет входящие: переключите
  сеть в «Частная» или добавьте в правило `-Profile Any`.

## Данные и миграция

Приложение использует единое JSON-хранилище в `server/data`. Запись выполняется
атомарно, а предыдущая версия каждого изменяемого файла сохраняется рядом с
расширением `.bak`.

Объекты имеют обязательные поля `name` и `address`. Фотографии химии хранятся
массивом `photo_urls` (до 10 изображений), а список химии сортируется по этапу,
дата которого ближе всего к текущему дню; записи без дат отображаются последними.

Перед первым запуском после обновления проверьте миграцию связей на числовые ID:

```powershell
npm run migrate:data
```

Команда по умолчанию работает без записи. После проверки примените миграцию:

```powershell
npm run migrate:data -- --apply
```

Миграция останавливается при неоднозначных или отсутствующих связях. Исходные
версии `objects.json` и `chemicals.json` сохраняются как `.bak`.

## Проверки

```powershell
npm test
npm audit --omit=dev
```

Поддерживаемые разделы: объекты, химия, часто задаваемые вопросы, жалобы и
уведомления. Старые экспериментальные SQLite-модули аналитики и экспорта удалены.
